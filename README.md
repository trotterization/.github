# Trotterization profile

The public organization README lives in [`profile/README.md`](profile/README.md).

The banner is an original procedural animation of a 4D Clifford torus. Regenerate it with:

```sh
python3 -m pip install -r scripts/requirements.txt
python3 scripts/render_banner.py
```

`profile/assets/trotterization.gif` is the looping banner. The PNG alongside it is a static preview.
